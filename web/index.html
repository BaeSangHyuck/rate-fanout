병렬 fan-out: 기관마다 코루틴을 띄워(async) 동시에 호출하고 awaitAll로 모읍니다. HTTP 호출은 WebClient라서 응답을 기다리는 동안 스레드를 잡지 않습니다. 전체 응답 시간은 합이 아니라 가장 늦게 끝난 호출로 정해집니다.

타임아웃: 호출마다 withTimeout을 걸어, 늦는 기관 하나 때문에 전체가 늦어지지 않게 합니다. 타임아웃은 재시도하지 않습니다. 이미 느린 기관을 다시 기다리면 그만큼 응답이 늦어지기 때문입니다.

부분 응답: 기관 실패를 예외로 올리지 않고 결과에 담습니다. 한 곳이 실패해도 나머지로 비교 결과를 돌려줍니다.

동시 호출 제한: Semaphore로 동시에 나가는 요청 수를 묶습니다. 외부 기관의 호출 제한이나 커넥션 풀을 넘지 않기 위해서입니다.
